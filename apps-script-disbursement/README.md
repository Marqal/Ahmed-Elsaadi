# مسمار — تقرير صرف الفواتير (Disbursement Report) · v1.0

سكربت **مستقل** عن سكربت مراقبة التدقيق. الغرض منه: يعمل نفس فلترة صفحة
«التكاليف» في الأدمن، **ويضيف رقم اللوحة** الذي لا يظهر في تلك الصفحة.

## آلية العمل
1. يجلب فواتير التكلفة B2B من `GET /adminApi/v2/orders-cost-invoices`.
2. **وضعان (Mode):**
   - `paid` — الفواتير المصروفة (تم الدفع / بالأجل) ضمن **تاريخ الصرف من–إلى**.
   - `unpaid` — الفواتير غير المصروفة (لا تاريخ صرف لها).
3. يفلتر **مكان الصرف** باسم المركز، ونوع الطلب ثابت `B2B_business`.
4. **رقم اللوحة غير موجود في صفحة التكاليف** → لكل طلب يدخل
   `GET /adminApi/v1/orders/{orderId}` ويستخرج اللوحة (أرقام + حروف، مثل
   `3039 ا س ط`)، **ويتحقق أن تاريخ الصرف مطابق للنطاق** (عمود «مطابقة التاريخ»).
5. يكتب النتيجة في تبويب **«تقرير الصرف»**.

## ⚠️ نقطتان تحتاجان تأكيدًا (بسبب أن الأدمن SPA)
بعض أسماء حقول الـAPI لا تظهر في HTML. لذلك:

- **وضع `unpaid` يعمل مباشرة** (`status=2` + `paymentMethodId` فارغ — مؤكّد من السكربت الأول).
- **وضع `paid`:** الأضمن أن تلصق **كويري بحث الأدمن** في خانة `RAW_QUERY`:
  1. افتح صفحة التكاليف وطبّق الفلاتر (تاريخ الصرف، حالة الدفع، المركز…).
  2. `F12` → تبويب **Network** → اضغط **بحث**.
  3. اضغط يمين على طلب `orders-cost-invoices` → **Copy → Copy link address** (أو انسخ كل ما بعد `?`).
  4. الصقه في الخلية `RAW_QUERY` بالإعدادات. عندها يجلب السكربت **نفس نتائج الأدمن** ويضيف اللوحة.

> لو أرسلت لي **عيّنة JSON واحدة** من `orders-cost-invoices` ومن
> `/adminApi/v1/orders/954222`، سأثبّت أسماء الحقول نهائيًا (تاريخ الصرف/المورد/
> النوع/المبلغ/اللوحة) وتستغني عن `RAW_QUERY`.

## هل الأفضل Looker Studio؟
**لا يغني عن السكربت.** Looker Studio أداة **عرض/داشبورد** فوق مصدر بيانات جاهز —
لا يستطيع مناداة API مسمار ولا الدخول لكل طلب ليجلب رقم اللوحة. التسلسل الصحيح:

```
Apps Script (يجلب + يستخرج اللوحة)  →  Google Sheet (تبويب «تقرير الصرف»)  →  (اختياري) Looker Studio
```

- لتقرير/قائمة يومية: **الشيت وحده يكفي** (فلترة، فرز، تصدير).
- لو أردت **داشبورد تفاعلي/مشاركة أوسع**: اربط Looker Studio بنفس الشيت
  (Looker Studio → Create → Data source → **Google Sheets** → اختر هذا الملف
  وتبويب «تقرير الصرف»)، وابنِ الرسوم فوقه. لكن **الاستخراج يظل بالسكربت**.

## طريقة التركيب
1. أنشئ **Google Sheet جديد** (منفصل عن ملف التدقيق).
2. **Extensions → Apps Script**.
3. الصق محتوى `Code.gs`، ثم (اختياري) من ⚙ Project Settings فعّل
   «Show appsscript.json» والصق `appsscript.json`. احفظ.
4. أعِد تحميل الشيت → تظهر قائمة **«تقرير الصرف»**.
5. **🔐 حفظ التوكن (آمن)** — الصق توكن مسمار (JWT).
6. **⚙ إعداد الشيت أول مرة** — ينشئ تبويب الإعدادات.
7. في تبويب «الاعدادات» اضبط: الوضع (`paid`/`unpaid`)، التواريخ، اسم المركز،
   و(لوضع paid) الصق `RAW_QUERY`.
8. **▶ تشغيل التقرير الآن**.
9. (اختياري) لجدولة يومية: Apps Script → Triggers → أضف تريغر زمني على
   `runDisbursementReport`.

## أعمدة التقرير
`رقم الطلب · رقم الفاتورة · رقم اللوحة · مكان الصرف · مورد الصرف · نوع الصرف ·
مبلغ الصرف · تاريخ الصرف · تاريخ الاستحقاق · حالة الدفع · مطابقة التاريخ`

- «مطابقة التاريخ»: ✅ مطابق / ⚠️ خارج النطاق / ⚠️ لا يوجد تاريخ صرف.
- «رقم اللوحة»: ⚠️ غير متوفر تعني أن حقل اللوحة باسم مختلف — أرسل لي عيّنة JSON للطلب.

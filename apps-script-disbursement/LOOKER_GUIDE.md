# دليل Looker Studio — تقرير صرف الفواتير

المصدر: تبويب **«بيانات الصرف»** في هذا الملف (يُملأ بزر «▶ سحب / تحديث البيانات»).
للإجماليات السريعة القابلة للتحميل، استخدم تبويب **«ملخص الصرف»** (زر «📊 بناء ملخص الصرف»).

---

## 1) الربط
1. افتح **[Looker Studio](https://lookerstudio.google.com)** → **Create → Report**.
2. **Add data → Google Sheets** → اختر هذا الملف → تبويب **«بيانات الصرف»** → **Add**.
3. تأكّد من أنواع الحقول (Data source): اجعل **تاريخ الصرف** و**تاريخ الاستحقاق**
   و**تاريخ الفاتورة** نوعها **Date (YYYY-MM-DD)**، و**المبلغ** نوعها **Number**.

## 2) الجدول الأساسي (رقم اللوحة · تاريخ الصرف · المبلغ)
1. **Add a chart → Table**.
2. **Dimensions:** `رقم اللوحة` ، `تاريخ الصرف` (وأضف `مكان الصرف` / `مورد الصرف` لو حبيت).
3. **Metric:** `المبلغ` واختر التجميع **SUM** (أو اتركه Record حسب رغبتك).
4. **الإجمالي أسفل الجدول:** تبويب **Style** للجدول → فعّل **Show summary row**
   → يظهر **مجموع المبلغ** أسفل الجدول. ✅ (ده «التوتال تحت»)

## 3) الفلاتر (Controls) — الأوبشنز المطلوبة
من **Add a control**، أضِف لكل فلتر:
- **مكان الصرف:** *Drop-down list* على `مكان الصرف` → فعّل **Allow multiple selections** (اختيار متعدد). ✅
- **مورد الصرف:** *Drop-down list* على `مورد الصرف` → **Allow multiple selections** → **أكثر من مورد**. ✅
- **حالة الدفع:** *Drop-down list* على `حالة الدفع`.
- **تاريخ الصرف:** *Date range control* على `تاريخ الصرف` (من – إلى).

> **أكثر من مدى تاريخ (من–إلى):** أداة Date range تعطي مدى واحد متصل. لاختيار
> **عدة فترات/شهور متفرقة**، أضف *Drop-down list* على عمود **الشهر** (multi-select)
> واختر مثلاً `2026-01` و`2026-03` و`2026-07` معًا. ✅ (أو عمود التاريخ نفسه).

## 4) الإجمالي لكل تاريخ (Subtotal per date)
أضِف **Pivot table**:
- **Row dimension:** `تاريخ الصرف` (أو `الشهر`).
- **Metric:** `المبلغ` = **SUM**.
- **Style →** فعّل **Row totals / Grand total**.
- كل صف تاريخ يعرض **إجمالي مبلغه**، ويظهر **الإجمالي الكلي** أسفل. ✅
- نفس الشيء جاهز في تبويب **«ملخص الصرف»** (بدون Looker) للتحميل المباشر.

## 5) التحميل
- **التقرير كله:** Share → **Download** (PDF)، أو Share للرابط.
- **جدول واحد:** مرّر عليه → **⋮ → Export** → CSV.
- **الشيت مباشرة:** في Google Sheets → **File → Download → Microsoft Excel (.xlsx)**
  أو **CSV**. نزّل تبويب **«بيانات الصرف»** (التفصيلي) أو **«ملخص الصرف»** (الإجماليات).

---

## إجابات سريعة
| السؤال | الإجابة |
|---|---|
| عرض اللوحة/التاريخ/المبلغ | ✅ Table + summary row |
| تحميل الشيت | ✅ File → Download، أو Export من Looker |
| فلترة (مكان/مورد/تاريخ/حالة دفع) | ✅ Controls (drop-down + date range) |
| إجمالي المبلغ أسفل | ✅ Show summary row / Scorecard SUM |
| أكثر من مورد | ✅ Drop-down multi-select |
| أكثر من مدى تاريخ | مدى واحد بالـDate range؛ **عدة شهور** عبر multi-select على «الشهر» |
| إجمالي تحت كل تاريخ | ✅ Pivot (تاريخ الصرف × SUM المبلغ)، أو تبويب «ملخص الصرف» |
